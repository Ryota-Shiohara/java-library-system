# 図書館システム

プログラミング第2同演習の最終課題用Javaプロジェクトです。

## ディレクトリ構成

```text
src/main/java/   アプリケーションのソースコード
src/test/java/   テストコード
scripts/         ビルド・実行・テスト・提出物作成用スクリプト
docs/            レポート原稿・設計資料
data/            実行時データ（自動生成・Git管理対象外）
out/             コンパイル済みファイル（自動生成・Git管理対象外）
output/          提出用ファイル（自動生成・Git管理対象外）
```
